# Security Policy

## Reporting a vulnerability

If you discover a security issue, please open a private security advisory on GitHub or contact the maintainer directly before publishing details.

Please include:

- A clear description of the issue
- Impact and affected versions
- Steps to reproduce
- Suggested mitigation, if available

## Response expectations

- Initial response target: within 7 days
- Fix timeline depends on severity and complexity

## Supported versions

Only the latest published major version is supported for security fixes.
